# 試験概要

出典: 公式 Exam Guide CLF-C02（実績済み）

## 基本

| 項目 | 内容 |
|------|------|
| 試験 | CLF-C02（Cloud Practitioner） |
| レベル | Foundational（Practitioner） |
| 言語 | 日本語可 |
| 受験料 | USD 100 |
| 有効 | 3年 |
| 配信 | Pearson VUE（会場 / オンライン） |
| 結果 | **合格**（2026/7/25） |

## 時間・問題・合格点

| 項目 | 内容 |
|------|------|
| 試験時間 | 90分 |
| 問題数 | 合計 65問（採点 50 + 非採点 15・識別不可） |
| ペース | 約 1.4分/問 |
| 合格点 | 700 / 1000（スケール。約 70%。素点%ではない） |
| 採点 | 補償型（ドメイン単体合格は不要） |
| 未回答 | 不正解扱い。推測ペナルティなし |

## 問題形式

| 形式 | 内容 |
|------|------|
| 択一（multiple choice） | 正解1・不正解3（計4肢） |
| 複数選択（multiple response） | 正解2以上・選択肢5以上。設問に「Nつ選べ」 |
| ラボ / 実技 | なし |
| 操作 | フラグ・前後移動・見直し可 |

## ドメイン配点

| # | ドメイン | 配点 |
|---|---------|------|
| 1 | Cloud Concepts | 24% |
| 2 | Security and Compliance | 30% |
| 3 | Cloud Technology and Services | 34% |
| 4 | Billing, Pricing, and Support | 12% |

前提: 一般 = 動画+本+ハンズオン+模試の典型。今回 = Cursor一問一答 + Anki + 模試（ハンズオン省略・合格最短）。

| 起点 | 一般 | 今回スタイル |
|------|------|-------------|
| AWS初心者（無資格） | 20–40h | **約 8h**（実績） |
| 現在の合格状況 | —（初資格） | 約 8h |

根拠（短く）:
- 一般: 初心者は 2–4週・週10h前後がよく出る幅
- 今回: 前夜+当日の集中で合格。実績ベース
