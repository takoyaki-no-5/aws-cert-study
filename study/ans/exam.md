# 試験概要

出典: [公式ページ](https://aws.amazon.com/certification/certified-advanced-networking-specialty/) / [Exam Guide ANS-C01](https://docs.aws.amazon.com/aws-certification/latest/advanced-networking-specialty-01/advanced-networking-specialty-01.html)

## 基本

| 項目 | 内容 |
|------|------|
| 試験 | ANS-C01（Advanced Networking - Specialty） |
| レベル | Specialty |
| 言語 | 日本語可 |
| 受験料 | USD 300（前資格で 50% 割引可） |
| 有効 | 3年 |
| 配信 | Pearson VUE（会場 / オンライン） |
| 廃止 | **2026/8/25 最終日**（計画の 10/10 は要見直し） |

## 時間・問題・合格点

| 項目 | 内容 |
|------|------|
| 試験時間 | 170分 |
| 問題数 | 合計 65問（採点 50 + 非採点 15・識別不可） |
| ペース | 約 2.6分/問 |
| 合格点 | 700 / 1000（スケール。約 70%。素点%ではない） |
| 採点 | 補償型（ドメイン単体合格は不要） |
| 未回答 | 不正解扱い。推測ペナルティなし |

## 問題形式

| 形式 | 内容 |
|------|------|
| 複数選択（multiple response） | 正解2以上・選択肢5以上 |
| matching | プロンプト3–7と対応づけ（Exam Guide） |
| 択一 | マーケ表記あり。ガイドは MR + matching |
| ラボ / 実技 | なし |
| 操作 | フラグ・前後移動・見直し可 |
