# 試験概要

出典: [公式ページ](https://aws.amazon.com/certification/certified-machine-learning-engineer-associate/) / Exam Guide MLA-C01

## 基本

| 項目 | 内容 |
|------|------|
| 試験 | MLA-C01（Machine Learning Engineer - Associate） |
| レベル | Associate |
| 言語 | 日本語可（英語は 2026/9/28 まで・C02 へ更新予定） |
| 受験料 | USD 150（前資格で 50% 割引可） |
| 有効 | 3年 |
| 配信 | Pearson VUE（会場 / オンライン） |
| 更新 | MLA-C02 beta 登録 2026/9/1〜。英語最終 9/28 |

## 時間・問題・合格点

| 項目 | 内容 |
|------|------|
| 試験時間 | 130分 |
| 問題数 | 合計 65問（採点 50 + 非採点 15・識別不可） |
| ペース | 約 2分/問 |
| 合格点 | 720 / 1000（スケール。約 72%。素点%ではない） |
| 採点 | 補償型（ドメイン単体合格は不要） |
| 未回答 | 不正解扱い。推測ペナルティなし |

## 問題形式

| 形式 | 内容 |
|------|------|
| 択一 / 複数選択 | あり |
| ordering / matching | あり（Exam Guide） |
| ラボ / 実技 | なし |
| 操作 | フラグ・前後移動・見直し可 |
