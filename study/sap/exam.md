# 試験概要

出典: [公式ページ](https://aws.amazon.com/certification/certified-solutions-architect-professional/) / Exam Guide SAP-C02

## 基本

| 項目 | 内容 |
|------|------|
| 試験 | SAP-C02（Solutions Architect - Professional） |
| レベル | Professional |
| 言語 | 日本語可 |
| 受験料 | USD 300（前資格で 50% 割引可） |
| 有効 | 3年 |
| 配信 | Pearson VUE（会場 / オンライン） |

## 時間・問題・合格点

| 項目 | 内容 |
|------|------|
| 試験時間 | 180分 |
| 問題数 | 合計 75問（採点 65 + 非採点 10・識別不可） |
| ペース | 約 2.4分/問 |
| 合格点 | 750 / 1000（スケール。約 75%。素点%ではない） |
| 採点 | 補償型（ドメイン単体合格は不要） |
| 未回答 | 不正解扱い。推測ペナルティなし |

## 問題形式

| 形式 | 内容 |
|------|------|
| 択一（multiple choice） | 正解1・不正解3（計4肢） |
| 複数選択（multiple response） | 正解2以上・選択肢5以上。設問に「Nつ選べ」 |
| シナリオ | 長文・複合が多い（Pro） |
| ラボ / 実技 | なし |
| 操作 | フラグ・前後移動・見直し可 |
