## 時間・問題・合格点

| 項目 | 内容 |
|------|------|
| 試験時間 | 130分 |
| 問題数 | 合計 65問（採点 50 + 非採点 15・識別不可） |
| ペース | 約 2分/問 |
| 合格点 | 720 / 1000（スケール。約 72%。素点%ではない） |
| 採点 | 補償型（ドメイン単体合格は不要） |
| 未回答 | 不正解扱い。推測ペナルティなし |

## 問題形式

| 形式 | 内容 |
|------|------|
| 択一（multiple choice） | 正解1・不正解3（計4肢） |
| 複数選択（multiple response） | 正解2以上・選択肢5以上。設問に「Nつ選べ」 |
| ラボ / 実技 | なし（テキストシナリオのみ） |
| 操作 | フラグ・前後移動・見直し可 |

## 学習時間（目安・h）

前提: 一般 = 動画+本+ハンズオン+模試の典型。今回 = Cursor一問一答 + Anki + 模試（ハンズオン省略・合格最短）。

| 起点 | 一般 | 今回スタイル |
|------|------|-------------|
| AWS初心者（無資格） | 120–150h | 約 45h（CLF 8h + SAA 36h） |
| CLF 合格済み（現在） | 60–100h | **36h**（=`plan.md`） |

根拠（短く）:
- 一般: クラウドゼロは 130–150h+、CLF 後でも 60–100h・4–8週がよく出る幅
- 今回: CLF 実績 ~8h（一般 20–40h の半分以下）。SAA は転送あり・シナリオ演習中心で 36h / 2週
