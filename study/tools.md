# 学習ツール

主に使うもの:

| ツール | 使い方 |
|--------|--------|
| **Cursor** | 計画・スケジュール・質問・解説・Anki TSV 生成・メモ整理 |
| **Anki** | 間隔反復。カードは基本ここ（エージェント）が TSV 生成 → Anki にインポート |
| **各種本** | 主教材。章・節をスケジュールの単位にし、要点は notes / Anki に落とす |

## Anki

- 生成物: `study/anki/*.tsv`
- 形式: Front / Back / Tags（タブ区切り・UTF-8・ヘッダなし）
- 詳細: `.cursor/skills/anki-tsv/SKILL.md`

## 本

- 一覧・進捗: `study/books.md`
- 持っている本・今読んでいる章をここに追記する
