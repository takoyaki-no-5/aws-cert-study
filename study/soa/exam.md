# 試験概要

出典: [公式ページ](https://aws.amazon.com/certification/certified-cloudops-engineer-associate/) / Exam Guide SOA-C03

## 基本

| 項目 | 内容 |
|------|------|
| 試験 | SOA-C03（CloudOps Engineer - Associate（旧 SysOps）） |
| レベル | Associate |
| 言語 | 日本語可 |
| 受験料 | USD 150（前資格で 50% 割引可） |
| 有効 | 3年 |
| 配信 | Pearson VUE（会場 / オンライン） |

## 時間・問題・合格点

| 項目 | 内容 |
|------|------|
| 試験時間 | 130分 |
| 問題数 | 合計 65問（採点 50 + 非採点 15・識別不可） |
| ペース | 約 2分/問 |
| 合格点 | 720 / 1000（スケール。約 72%。素点%ではない） |
| 採点 | 補償型（ドメイン単体合格は不要） |
| 未回答 | 不正解扱い。推測ペナルティなし |

## 問題形式

| 形式 | 内容 |
|------|------|
| 択一（multiple choice） | 正解1・不正解3（計4肢） |
| 複数選択（multiple response） | 正解2以上・選択肢5以上。設問に「Nつ選べ」 |
| ラボ / 実技 | なし |
| 操作 | フラグ・前後移動・見直し可 |

## ドメイン配点

| # | ドメイン | 配点 |
|---|---------|------|
| 1 | Monitoring, Logging, Analysis, Remediation, Performance | 22% |
| 2 | Reliability and Business Continuity | 22% |
| 3 | Deployment, Provisioning, and Automation | 22% |
| 4 | Security and Compliance | 16% |
| 5 | Networking and Content Delivery | 18% |
