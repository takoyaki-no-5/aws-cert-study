# 試験概要

出典: [公式ページ](https://aws.amazon.com/certification/certified-developer-associate/) / Exam Guide DVA-C02

## 基本

| 項目 | 内容 |
|------|------|
| 試験 | DVA-C02（Developer - Associate） |
| レベル | Associate |
| 言語 | 日本語可 |
| 受験料 | USD 150（前資格で 50% 割引可） |
| 有効 | 3年 |
| 配信 | Pearson VUE（会場 / オンライン） |

## 時間・問題・合格点

| 項目 | 内容 |
|------|------|
| 試験時間 | 130分 |
| 問題数 | 合計 65問（採点 50 + 非採点 15・識別不可） |
| ペース | 約 2分/問 |
| 合格点 | 720 / 1000（スケール。約 72%。素点%ではない） |
| 採点 | 補償型（ドメイン単体合格は不要） |
| 未回答 | 不正解扱い。推測ペナルティなし |

## 問題形式

| 形式 | 内容 |
|------|------|
| 択一（multiple choice） | 正解1・不正解3（計4肢） |
| 複数選択（multiple response） | 正解2以上・選択肢5以上。設問に「Nつ選べ」 |
| ラボ / 実技 | なし |
| 操作 | フラグ・前後移動・見直し可 |

## ドメイン配点

| # | ドメイン | 配点 |
|---|---------|------|
| 1 | Development with AWS Services | 32% |
| 2 | Security | 26% |
| 3 | Deployment | 24% |
| 4 | Troubleshooting and Optimization | 18% |

## 学習時間（目安・h）

前提: 一般 = 動画+本+ハンズオン+模試の典型。今回 = Cursor一問一答 + Anki + 模試（ハンズオン省略・合格最短）。

| 起点 | 一般 | 今回スタイル |
|------|------|-------------|
| AWS初心者（無資格） | 80–120h | 約 247h（全経路〜DVA） / 単体なら約 36h |
| ANS 合格済み（現在の予定・SAA 転送あり） | 40–70h | **28h**（=`plan.md`） |

根拠（短く）:
- 一般: Associate。開発経験があると短くなる
- 今回: SAA 一部再利用・模試中心。必要量 28h / 2週
