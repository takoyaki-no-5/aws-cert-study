# Anki（SAP）

```
study/anki/sap/
  01-service-list/   … サービス名→一言（テキスト表）
  02-.../            … 掘り下げ（インスタンス種別など・これから）
  05-mock/
  06-review/
```

方針: **名前＋一言 → 掘り下げ**を段階追加。形式は `study/anki/README.md`。

| ファイル | 枚数 | 内容 |
|----------|------|------|
| `01-service-list/03-analytics.tsv` | 12 | 分析 |
| `01-service-list/04-application-integration.tsv` | 7 | アプリケーション統合 |
| `01-service-list/05-blockchain.tsv` | 1 | ブロックチェーン |
