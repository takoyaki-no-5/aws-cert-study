# 日次学習セッション

## 開始時

1. `study/profile.md`・`study/schedule.md`・今日の `study/log/YYYY-MM-DD.md`（あれば。前日ログも有用なら）を読む。
2. プロフィールに目標資格・期限・学習時間が欠けていれば、足りない分だけ聞いて `study/profile.md` に書く。
3. **今日の計画**を日本語で提案: 時間ブロック・トピック・達成基準（例:「〜を説明できる」「練習問題〇問」）。
4. 最初のブロックの開始を促す（すでに「始めて」と言われていたら即開始）。

## セッション中

- 1ブロックずつ進める。カリキュラム全体を一気に出さない。
- 質問には試験目線で回答。紛らわしい選択肢の対比も添える。
- 計画が途中で変わったら `study/schedule.md` を更新。

## 終了時（またはユーザーが切り上げたとき）

- `study/log/YYYY-MM-DD.md` に追記・更新: できたこと / できなかったこと / 次にやること。
- 必要なら `study/schedule.md` の翌日分を調整。
- 一言の励まし + 明確な次のアクションで締める。
