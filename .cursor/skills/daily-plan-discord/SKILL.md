# 今日の予定 / 進捗 → Discord

固定タスク（どちらも **ユーザーが伝えたタイミング** で動かす。勝手に定期送信しない）:

1. **予定**: 今日の予定を出す →（必要なら調整）→ Discord
2. **進捗**: どこまでやったかを受け取る → day/log 更新 → Discord

## 前提

- 1日の学習枠（`study/profile.md` を正）:
  - **帰宅後 2時間40分（160分）** … テキスト中心（Discord に書くのはこの枠だけ）
  - **電車 Anki 30分** … 帰宅後の**外**（別枠。**Discord には書かない**）
  - 当日だけ短縮（例: 2時間）ならユーザー指定を優先し day に明記
- Webhook: Cloud Secret / env **`discord_daily_bot`**
- 送信: `python3 .cursor/hooks/discord-notify.py`（URL をログに出さない）
- チャット向け（本人用）は day / 技術用語OK。**Discord 向けは友達向け・別フォーマット**

## Discord 文面ルール（予定・進捗共通）

宛先は **友達**（分野外でもわかる・フランク・短い）。

| やる | やらない |
|------|----------|
| 「SAA資格の勉強」など資格が何か一言 | `01-secure` / ELB / roadmap / ドメイン配点 |
| 「教科書（全N章）の〇章」 | サービス名の羅列、ファイルパス |
| 「暗記アプリを〇分」 | Anki・デッキ名・TSV |
| 帰宅後枠のタスクだけ並列リスト | **電車 Anki・枠外のこと** |
| 並列の `-` リスト（タスク並記はそのまま） | 長い表、不足リスト、受験戦略 |

教科書の総章数は進行中資格のテキストに合わせる（SAA 改訂第3版は **全14章**）。

---

## A. 予定（開始時）

1. 読む: `study/profile.md` / `study/schedule.md` → 進行中 `study/<資格>/schedule.md` / 今日の `days/` / 直近 `study/log/` / 必要なら `books.md`
2. 今日の day が無ければ、未消化・roadmap・残り日数から **帰宅後160分＋電車30** に収まる案を作る（まだ確定・送信しない）。足りない分は schedule の「不足」へ
3. **ズレ検知** → 当てはまったら先に質問（勝手に詰め込まない）
4. **チャット**には本人向けに具体ブロックを短く提示
5. OK なら Discord は下の**友達向け**で送信。調整があれば「調整」へ

### 予定メッセージ（Discord）

```
今日の勉強（SAA資格）
M/D・〇時間〇分

- 教科書（全14章）の 3章・9章を読む
- 暗記アプリを20分
```

- 1行目: 何の勉強か
- 2行目: 日付と帰宅後の長さだけ
- 以下: 帰宅後枠のタスクを `-` で並列（読む / 問題を解く / 暗記アプリ など平易な動詞）
- 暗記アプリが帰宅後枠に無い日は書かない（電車分は書かない）

### チャット（本人向け・例）

日付・時刻・章・「いまやること」は今までどおり短くてよい（技術名OK）。Discord にコピペしない。

---

## B. 進捗（ユーザーが伝えたとき）

トリガー例:「第3章終わった」「ここまでやった」「進捗送って」「今日ここまで」「切り上げ」

1. 報告 + 今日の `days/` を照合（曖昧なら確認してから）
2. day のチェックと `study/log/YYYY-MM-DD.md` を更新
3. Discord は下の進捗フォーマット（予定と混ぜない）
4. チャットにも一言

**言われるまで送らない。**

### 進捗メッセージ（Discord）

```
勉強進捗（SAA資格）
M/D

できた:
- 教科書の 3章
- 暗記アプリ 20分

まだ:
- 教科書の 9章

次: 9章から（ or 今日はここまで）
```

枠外（電車など）は書かない。できた/まだも平易な言葉だけ。

---

## 送信

```bash
python3 .cursor/hooks/discord-notify.py "$(cat <<'EOF'
今日の勉強（SAA資格）
...
EOF
)"
```

成功後「Discord 送信済み」。失敗時はチャットに内容を残す。

## 調整（「これもやる」「これはやらない」）

day / 予定を反映 → 必要なら Discord **再送**（先頭に「訂正:」）。

| 指示 | 動き |
|------|------|
| やらない・スキップ | 外す。空きを次に振るか不足に回すか聞く |
| これもやる・追加 | 時間が分かる → 帰宅後枠に収まる案を確認。不明 → **分数を聞いてから** |
| 順番変更 | 枠と「テキスト→Anki最後」を崩さない範囲で |

### 質問してから動く（必須）

所要不明・160分超え／ズレ・進捗範囲が曖昧・合格リスクが変わる削り → **推測で確定しない**。

## ファイル更新

- 予定 → `study/<資格>/days/YYYY-MM-DD.md`
- 進捗 → 同 day + `study/log/YYYY-MM-DD.md`
- 大きな配分変更 → 進行中 `schedule.md`

## やらない

- Webhook URL をコミット・貼る
- Discord に技術用語・枠外（電車 Anki 等）・不足リストを載せる
- 時間不明の追加を黙って押し込む / ズレを黙って玉突き
- 進捗を推測して勝手に送信
